# Laptop Tracker

A Python-based anti-theft laptop tracking system.

## Features
- Captures intruder photo using webcam
- Takes screenshot automatically
- Sends photo and screenshot to Telegram
- Sends IP-based location details
- Plays alarm sound
- Can run automatically at startup

## Technologies Used
- Python
- OpenCV
- Telegram Bot API
- PyAutoGUI
- Requests
- Pygame
